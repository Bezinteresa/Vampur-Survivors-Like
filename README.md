# Vampur Survivors-Like

2D-рогалик «выживание на арене» для браузера (Vue 3 + Three.js + TypeScript), книжная ориентация, телефон в первую очередь.
Дизайн-документ: [docs/GDD.md](docs/GDD.md).

## Статус

Прототип боя (этап 1–2 из GDD): графика — заглушки (цветные круги), звука нет, лобби нет, Playgama Bridge ещё не подключён.

Что уже работает:
- движение: WASD/стрелки или плавающий джойстик (палец в любом месте экрана);
- две способности: кувырок (Пробел, 8 с) и скорострельность (E, 35 с); пауза — P или кнопка (Esc не используется);
- 10 волн с таймером (40 с + 10 с за волну), на 10-й — босс с замахом и рывком;
- 3 вида мобов, рост их силы по волнам, метки появления;
- 10 видов оружия четырёх типов урона: пули (пистолет, пистолет-пулемёт, дробовик, арбалет), ближний бой (меч), магия (цепная молния, огненный жезл, ледяной посох), механика (дрон, турель); 5 ступеней (I–V);
- эффекты: горение и кровотечение (урон со временем), заморозка (замедление);
- одна валюта забега — она же опыт;
- после волны: выбор карточек (по одной на уровень, 4 редкости), обновление за монеты: 2 × волна (не меньше 4), ×2 за каждое;
- магазин: 3 предложения (оружие и предметы забега), замок, обновление; цены растут с волной; 6 слотов оружия, повторное оружие встаёт в свободный слот, два одинаковых одного тира объединяются вручную; продажа;
- 18 предметов забега, многие с плюсом и минусом, лимит стопки; особые: «Медитация» (лечение стоя), «Сорока-сборщица» (притягивает монеты);
- аптечки с мобов; характеристики кражи жизни, получения опыта, лечения аптечкой;
- сундук снабжения на волнах 2–9: стоять в кольце, пока оно заполнится → бесплатный выбор 1 из 3 оружий;
- окно оружия: урон за волну и за забег; пауза показывает оружие, предметы и характеристики.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5190
npm run build    # проверка типов и сборка в dist/
```

В dev-режиме в консоли доступен `window.__game` (например, `__game.debugAdvance(10)` прокручивает 10 секунд боя).

## Устройство кода

| Путь | Что |
|---|---|
| `src/game/World.ts` | симуляция боя: герой, мобы, оружие, снаряды, монеты |
| `src/game/Game.ts` | ход забега: волны, спавн, уровни, карточки, магазин, цикл кадров |
| `src/game/Renderer.ts` | отрисовка Three.js (ортографическая камера, instanced-меши) |
| `src/game/Input.ts` | клавиатура и джойстик |
| `src/game/SpatialGrid.ts` | сетка для быстрого поиска соседей |
| `src/game/data/` | таблицы: оружие, мобы, волны, способности, карточки |
| `src/ui/` | интерфейс Vue: HUD, карточки, магазин, свои SVG-значки |
