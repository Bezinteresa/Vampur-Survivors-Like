# Bogatyr Survivors

Название игры — **Bogatyr Survivors** (одинаковое на всех языках; так же в заявке Playgama, п. 3.5.1). Папка и ключи сохранений остались со старым рабочим названием `vampur`.

2D-рогалик «выживание на арене» для браузера (Vue 3 + Three.js + TypeScript), книжная ориентация, телефон в первую очередь.
Дизайн-документ: [docs/GDD.md](docs/GDD.md).

## Статус

Этапы 1–3 из GDD: бой и лобби. Графика — заглушки (цветные круги), звука нет, Playgama Bridge ещё не подключён, сохранение пока в localStorage (только для разработки).

Что уже работает:
- движение: WASD/стрелки или плавающий джойстик (палец в любом месте экрана);
- две способности: кувырок (Пробел, 8 с) и скорострельность (E, 35 с); пауза — P или кнопка (Esc не используется);
- 10 волн с таймером (40 с + 10 с за волну), на 10-й — босс с замахом и рывком;
- сеттинг — древнерусская сказка: 8 локаций с хозяевами-боссами (Леший, Кикимора, Водяной, Соловей-Разбойник, Лихо, Баба Яга, Змей Горыныч, Кощей) и прихвостнями под стать; 9 типов поведения мобов (дробь, лучи, сходящиеся лучи, ракеты, перекат, ядовитые лужи, деление, воришка с монетами); у Кощея — яйцо с иглой;
- 10 видов оружия четырёх типов урона: пули (пистолет, пистолет-пулемёт, дробовик, арбалет), ближний бой (меч), магия (цепная молния, огненный жезл, ледяной посох), механика (дрон, турель); 5 ступеней (I–V);
- эффекты: горение и кровотечение (урон со временем), заморозка (замедление);
- одна валюта забега — она же опыт; не поднятые до конца волны монеты копятся в копилке и выдаются по +1 к каждой поднятой в следующих волнах;
- после волны: выбор карточек (по одной на уровень, 4 редкости), обновление за монеты: 2 × волна (не меньше 4), ×2 за каждое;
- магазин: 3 предложения (оружие и предметы забега), замок, обновление; цены растут с волной; 6 слотов оружия, повторное оружие встаёт в свободный слот, два одинаковых одного тира объединяются вручную; продажа;
- 18 предметов забега, многие с плюсом и минусом, лимит стопки; особые: «Медитация» (лечение стоя), «Сорока-сборщица» (притягивает монеты);
- аптечки с мобов; характеристики кражи жизни, получения опыта, лечения аптечкой;
- сундук снабжения с 4-й волны с шансом 40%: стоять в кольце, пока оно заполнится → бесплатный выбор 1 из 3 оружий;
- окно оружия: урон за волну и за забег; пауза показывает оружие, предметы и характеристики.

Лобби:
- карта из 8 локаций (враги сильнее ×1 … ×6,2), лучший результат «волн из 10», следующая открывается победой над боссом;
- экипировка: 6 слотов (оружие, шляпа, очки, куртка, рюкзак, сапоги) и 2 слота способностей; 6 рангов, предел уровня 10…60;
- карточка предмета: основной бонус за уровень, 5 привилегий по рангам ("собственные" — только для этого оружия), комплект, улучшение золотом и чертежами, макс. улучшение, разборка, продажа;
- слияние 3 одинаковых предметов одного ранга в следующий ранг, кнопка «Объединить всё»;
- 5 комплектов одежды (бонус с 4 надетых вещей), 5 способностей-предметов (кувырок, скорострельность, перевязка, ледяная волна, ударная волна);
- 8 богатырей на выбор (урон и здоровье по уровню до 25, особенность от кувырка), открытие за кристаллы, улучшение золотом и живой водой;
- 12 талантов за золото; магазин сундуков (малый бесплатно раз в 4 часа или за золото, средний и большой за кристаллы);
- награды за забег: золото, кристаллы за победу, чертежи, предметы; экран наград; «Сдаться» на паузе.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5190
npm run build    # проверка типов и сборка в dist/
```

В dev-режиме в консоли доступны `window.__game` (например, `__game.debugAdvance(10)` прокручивает 10 секунд боя) и `window.__meta` (профиль лобби). Сброс прогресса: `localStorage.removeItem('vampur.save')`.

Камера и размер богатыря: кнопка-шестерёнка в бою (в dev-сборке, а в обычной — при адресе с `?tune`): ползунки (камера в начале боя и после отъезда, задержка и длительность отъезда, размер богатыря), кнопки «Начало боя» и «После отъезда», строка значений для переноса в `src/game/view.ts`.

Ускорение игры: `__game.timeScale = 10`. Посмотреть, как играет бот, в реальном времени на ×10: `__balance.watch('P0', 0, 10)`.

Важно: во время разработки Vite перезагружает страницу (или пересоздаёт приложение) при правке кода — забег при этом сбрасывается в лобби. Для спокойной игры: `npm run build` и `npm run preview` (http://localhost:4174).

Баланс: в dev-режиме `__balance.series('P1', 0, 6)` — бот играет забеги с профилем прокачки P0–P3 на выбранной локации и выдаёт сводку (победы, волны, покупки, время боя с боссом, золото, источники урона). Цели и последние замеры — [docs/GDD.md](docs/GDD.md), раздел 13.

## Графика

По пайплайну `H:/Html AI/ART_PIPELINE_PROMPT.md`:
- `art/generation-prompts.json` — список всех картинок игры (181 шт.): путь, размер, описание, правила кадра, общий стиль.
- `node art/art_todo.mjs` — собирает `art/ART_TODO.md`: только то, чего ещё нет (или размер не тот, или стоит `redo`).
- `python art/save_generated_asset.py <исходник> <файл> <ширина> <высота>` — кладёт картинку в `public/sprites/<файл>` нужного размера.
- `python art/compress_sprites.py` — сжимает тяжёлые PNG (оригиналы в `art/originals`).
- `python art/verify_generated_assets.py` — проверка размеров и прозрачности, превью-листы в `art/generated-previews`.

Порядок: сначала `hero/ivan.png` — он же образец стиля (`References/style.png`), потом остальное с этим образцом.

Игра сама подхватывает картинки: файл есть в `public/sprites` — рисуется он, нет — заглушка (цветной круг, текст). В dev-режиме новая картинка видна после автоматической перезагрузки страницы. Список файлов собирает плагин Vite (`virtual:sprite-list`), код — `src/sprites.ts`.

## Звук (все источники CC0)

Только записанные файлы (Playgama 3.3.2), без синтеза в коде. Лежат в `public/audio`, копирует `python scripts/prepare_audio.py` из общей папки `H:/Html AI/resources/audio`; играет `src/audio/sound.ts`. Кнопка звука — в лобби и на паузе: выключить всё, громкость музыки и эффектов (хранится в профиле). Пока платформа запрещает звук, вкладка скрыта, игра на паузе или открыта реклама — тишина.

## Устройство кода

| Путь | Что |
|---|---|
| `src/game/World.ts` | симуляция боя: герой, мобы, оружие, снаряды, монеты |
| `src/game/Game.ts` | ход забега: волны, спавн, уровни, карточки, магазин, цикл кадров |
| `src/game/Renderer.ts` | отрисовка Three.js (ортографическая камера, instanced-меши) |
| `src/game/Input.ts` | клавиатура и джойстик |
| `src/game/SpatialGrid.ts` | сетка для быстрого поиска соседей |
| `src/game/data/` | таблицы: оружие, бестиарий (`bestiary.ts`: локации, мобы, боссы), волны, способности, карточки |
| `src/game/enemyAi.ts` | поведение мобов и боссов |
| `src/game/loadout.ts` | что лобби передаёт в забег и что забег возвращает |
| `src/meta/` | лобби: содержимое (предметы, комплекты, таланты, локации, сундуки), профиль и экономика (`Meta.ts`), сохранение |
| `src/ui/` | интерфейс Vue боя: HUD, карточки, магазин, свои SVG-значки |
| `src/ui/lobby/` | интерфейс лобби: карта, экипировка, карточка предмета, таланты, магазин сундуков |
